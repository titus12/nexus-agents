# Zhongshu option-comparison boundary

This attachment does not prescribe an option matrix for Zhongshu requirement
formalization. The former mandatory comparison guide is retired.

Use the canonical requirements, supplied evidence, the active Zhongshu Solver
skill and the injected result contract. Do not invent architecture options,
performance numbers, implementation detail or future measurements solely to
satisfy an old checklist. A comparison is needed only when the current user
request explicitly asks for it; keep it at the requested requirement boundary.

Menxia design requirements are defined by its separate active skill and contract.
