# 中书省契约与分组冻结修复

用户在最新日志排查后回复「修复」，批准修复已确认的三处缺陷。

1. 分组 ID 是稳定标识，不绑定 `group-数字` 前缀。支持 ASCII 字母/数字开头及字母、数字、下划线、点、连字符；契约、解析和修复共享规则。标题必须与所属 group_id 完全一致，禁止自动改写另一组的标识，保留版本校验。错误反馈包含所属组、实际首行和准确格式。
2. 任务 DAG 投影到分组后也必须是 DAG。按冻结机制相同的成员依赖规则检查，忽略组内边，返回明确的环路径和拆组建议。该缺陷走现有有界 Solver 重试，不进入 Critic 或冻结等待；其他原有致命错误语义保持。
3. 定性可行性评估不是实测收益承诺。仅豁免没有明确收益断言/数值结果的可行性、是否存在优化空间等评审要求；数值收益和确定性改善承诺仍需实测或待实测标记。

人工审查循环保持：仅精确「通过」进入门下省，其余反馈由 Solver 修订并再次人工审查，不增加 Critic。

回归时额外确认：Solver 拒绝路径通过通用 transition helper 把无效 reply 投影进 review，
造成后续初稿被误当修订、错误冻结编辑范围。拒绝重试与耗尽阻塞均不得更新权威 review；
保留投递结果、失败记录与审计，仍以最后已接受方案作为重试上下文。
