# .NET Workflow Routing

Use the narrowest matching .NET workflow:

- `$wf-dotnet-feature` for a new class-library or hosted-service capability.
- `$wf-dotnet-bugfix` for a confirmed build, test, runtime, configuration,
  concurrency, or cancellation defect.
- `$wf-dotnet-review` for a read-only review of a .NET change.

Before implementation, read this rule, the applicable `dotnet-*` safety rules,
and the relevant .NET skills. Do not route .NET work through Unity workflows
or tools.
