# unity-00-routing

Route Unity work through explicit workflow entries: `$wf-unity-bugfix`, `$wf-unity-logic-mod`, `$wf-unity-ui-feature`, and `$wf-unity-ui-quick`.

Use bug investigation for failures, logic modification for non-UI behavior changes, full UI feature development for UGUI, TMP, UIArchitect, Prefab, Scene, Resolver, or presentation work, and the UI quick workflow only for its explicitly bounded narrow UI changes.
