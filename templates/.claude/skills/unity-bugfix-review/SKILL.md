# Unity Bug 修复审查规范

在审查 Unity Bug 修复时按需读取；不得据此隐式启动或选择工作流。

## 审查重点

- 修复是否针对已确认根因，且改动范围是否仅覆盖直接相关的必要内容；若范围扩大，是否有明确理由和验证。
- 是否引入空值、生命周期、已销毁对象、临时资源或资产安全风险。
- 是否留下调试代码、临时开关、重复逻辑或无关变更。

## 验证要求

- 检查编译、Console、复现与回归证据是否足以支持结论。
