# 审核反馈动态纳入规范

> 触发：审核完成后发现 rules 未覆盖的风险模式
>
> §1 机制 §2 纳入流程 §3 原则

## §1 机制

审核过程中（reviewer 或用户）发现的新风险模式，如果现有 rules 未覆盖，主动建议纳入规范。

## §2 纳入流程

1. 向用户提示：
   ```
   审核中发现新的风险模式：[描述]
   当前规范未覆盖此类问题。是否纳入 [对应 rule 文件]？
   ```
2. 用户确认 → 更新对应 rule 文件
3. 用户拒绝 → 记录到"已评估不纳入"

## §3 纳入原则

- 只纳入重复出现或高风险的模式（偶发性不纳入）
- 纳入时给出具体可执行的检查规则
- 每条规则标注负责检查的 reviewer 角色
- 规范只增不减（除非用户确认已过时）
